# PreBuyScan

**Scan before the scam.** Revisa antes de comprar. Por VIGIA.

Revisión rápida de señales de riesgo de tokens en Robinhood Chain: liquidez, ventas, dueño del contrato, funciones peligrosas (mint, lista negra, comisiones, pausa) y contratos actualizables.

Todo corre en tu navegador con datos públicos (DexScreener y la RPC pública de Robinhood Chain). No pide wallet, no firma nada y no guarda datos.

**Aviso:** herramienta informativa, no asesoría financiera ni auditoría. «Sin alertas» no significa «seguro» y ninguna revisión garantiza que puedas vender.
